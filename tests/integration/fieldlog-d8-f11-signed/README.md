# FieldLog D8 F11 host replay

The driver recovers the exact ordinary Android F11 seed from the retained
API 36 fixture and rehashes the three original 20-change corpus source
anchors. It rebuilds the installed Pair25 app source tree locally and compiles
its model, workspace repository, and Android entry editor sources.

The stock loopback origin serves a newly signed Android-scoped V3 prior and
successor. The prior reads the restored note through app-private storage and
displays its exact bytes in a read-only frame. The successor projects the
Pair25 vertical note field and its original action bindings. The stock V1
validator rejects the first editable document before an action can be
delivered. Rollback restores the read-only prior. A fresh process opens the
same rollback candidate with the origin closed and verifies the same note
and workspace bytes. This is a reauthored host witness of the signed boundary.

A separate direct signed launch under the pinned private F04 task-retry owner
probes the F11 note key under the F04 namespace. The guest observes permission
denied before the repository receives a read. Codec probes independently test
the original vertical field and the same document with only its axis removed.
The ordinary editor control separately saves the archived ASCII append,
reopens the saved draft cold, commits, and verifies cold readback and zero
writes from a repeated commit. The original driver assertions verify unchanged
unrelated JSON and one linked event. Normalizing the commit's fresh UUID
and timestamp reproduces the archived installed workspace hash.

Run from the Mixer checkout with local stock origin and CLI binaries from the
F08/F09 replay, offline Git and dependency caches, Xcode, and the local Swift
6.3.3 clang and wasm-ld. The Stage argument supplies the pinned Git blobs and
retained fixture scripts. Use a new owned scratch path under
`verification/local/`.

```bash
bash tests/integration/fieldlog-d8-f11-signed/replay.sh \
  "$stage" "$local_fieldlog" "$stock_tools" "$work" > "$receipt"
```

The driver checks closure of the local origin and the child hosts. Remove the
owned scratch after a terminal run. The compact receipt records the actual
boundary and the ordinary behavior. Signed note mutation and installed signed
behavior remain pending.
