A simple explanation of how this website works and what happens when you use it.

About this notice

This notice covers the Mixer marketing website and documentation you’re reading.

A question?

Open a GitHub issue ↗ without including private or sensitive information.

A small, static website.

These pages are static HTML, styles, local images, and a small JavaScript file. This website does not use analytics, tracking pixels, advertising scripts, or cookies. It does not offer a login or collect information through a submission form.

The interactive parts stay in your browser.

The workflow example on the home page is a local demonstration. Trying an update changes the example on the page; it does not create an account, build an app, or publish a release.

Copy buttons copy the displayed command or example to your clipboard when you click them. Navigation, copy feedback, and the demonstration run in your browser. These interactions do not send their contents to Mixer.

Fonts and assets.

The site uses your system fonts. Images, icons, styles, and scripts are served with the website. It does not load a third-party font service or embed third-party media.

Delivering the pages.

When you load a page or download an asset, the web host may receive technical request data such as your IP address, the requested URL, browser information, and the time of the request. That information is part of delivering and operating the website. This notice does not specify the host’s retention practices.

Links to other services.

Links to the source repository, issues, and other GitHub pages take you to GitHub. Your use of that service is covered by GitHub’s privacy statement and settings.

If you post an issue, the information you choose to share may be public. Keep credentials, private keys, customer data, and other sensitive details out of public posts.

The scope of this notice.

This page describes this website. It does not describe data handling for the Mixer hosted service, native applications built with Mixer, or your own application’s backend. Those services and applications need privacy information appropriate to how they operate.

You can inspect the website source in the Mixer repository.
