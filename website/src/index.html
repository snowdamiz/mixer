Good questions.

Are these really native apps?

Yes. Mixer compiles your Swift application for iOS and Android and renders supported UI through native platform controls. Native integrations remain available through platform adapters and custom extensions.

Can I bring an existing Swift app?

Yes. Start with a compatibility assessment and migrate one screen or feature at a time. Shared interfaces use MixerUI; existing SwiftUI code may need adaptation. You can keep platform-specific screens and integrations along the way.

What can I update over the air?

Compatible app logic and supported UI changes within the installed app’s capabilities. Mixer checks the runtime and release contracts before distribution. New native code, permissions, entitlements, and runtime changes go through a new store release.

Do I have to use Mixer’s cloud?

No. Create projects, develop, build locally, and export native projects without a cloud account. The hosted service adds managed builds, distribution, release controls, and team workflows.

What happens if an update goes wrong?

Signed artifacts, compatibility checks, staged rollout, and local recovery work together. You can halt a rollout or roll back to a compatible healthy release. Offline devices continue using their installed healthy app.

Can I use my own backend and tools?

Absolutely. Bring your existing backend, use your preferred editor, and open generated native projects in Xcode or Android Studio. Mixer fits into your workflow, including automation through the CLI and release API.
