# Branded Builds screen checkpoint

The local SolidJS console now has a Builds screen using the website’s exact Flick
logo, cream-and-orange palette and typography, with shared navigation and a route-aware
breadcrumb. Each platform keeps its own build identity, attempt and outcome. Missing
updates remain visible; cancellation and deadline reconciliation preserve uncertainty.
Detailed input hashes are available in an expandable section.

Root accepts 32 repository tests, seven independent controls and 117 text-boundary
comparisons against the actual Elixir lifecycle. Fourteen reactive browser states,
320/375/1280-pixel layouts, keyboard expansion and skip-link focus, native select
commit, and production navigation pass. Both synthetic preview routes are excluded
from production. All root browser tabs, servers and disposable production output
were cleaned up.

Independent review found a mismatch between JavaScript character lengths and the
backend’s UTF-8 byte bounds. The repaired validator matches the backend’s printable
text behavior and preserves legitimate whitespace. Browser inspection also found
that the preview selector extended beyond its card at 320 pixels despite no page-wide
overflow; a narrow CSS correction now passes control-containment checks. Original
attempts and pre-correction receipts remain preserved.

This is an internal read-only view model. Production `/builds` and `/releases`
truthfully report that no data source is connected. Authenticated Phoenix data,
durable orchestration, real workers, signing/distribution, full accessibility and
cross-browser qualification, deployment, and G22/GA acceptance remain pending.

The [root acceptance](../verification/console-build-overview-root-review/acceptance.json)
binds the final source, independent review, CSS supplement and browser evidence.
The [component contract](console-build-overview.md) records field semantics and
[the independent review](console-build-overview-independent-review.md) records
its scope and resolved finding.
