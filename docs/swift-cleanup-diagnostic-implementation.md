# Private contextual live-removal diagnostic candidate

This isolated producer candidate repairs the selected current-invocation
attribution gap at the original control failure boundary. It is prepared for
independent review and root integration. It is not live-integrated or accepted
for G08, native platforms, public Swift invocation, FieldLog or GA.

The authoritative baseline is the accepted 128-file host-operation archive,
closure `7ee6194584a5029ff2bbbcb94f8286295411cb3441a04db30c8fd4036d851329`.
The candidate closure is
`1e89853d56f0ae46720cb0e9d72a4a2a13003f777e1d01f65db154f30782ed9c`.
Source bytes, not the contextual Git revision, bind this packet. The root's
selected contract and host-baseline direction, the complete accepted upstream
bindings and the original contract packet are retained and hash-bound. The
initial rebase direction identified the new active host post-truncate removal
before behavioral implementation.

## Failure boundary and scope

`RuntimeControl::remove_live_at_with_wasi(resource, amount, cursor, wasi)` is a
new private entry alongside the unchanged old method. The entire legacy
`remove_live_with_wasi` body remains byte-exact. There is no common-body
refactor. The new entry uses the same original `live_parts`, checked subtraction
and `live_mut` primitives. Successful and zero removals preserve original live
counts and peaks without an ordinary check, work/fuel debit, allocation or
stored cursor.

On an underflow, the new entry sets the existing independent `LiveUnderflow`
latch and calls original `fail` immediately. It supplies the caller's cursor,
exact `Live` resource mapping, requested removal amount and current available
count. The limit is available count, not configured capacity. Existing first
failure authority wins in every field. No wrapper appends source data later.
`record_cleanup` continues to update only the distinct `after_cleanup`
observation. Representable counts are exact on the qualified 64-bit macOS host.

The selected active callers are original value pop, numeric reconciliation,
shared control removal, a separate explicit active-finish helper used by exactly
three finish removals, and host-operation removal after actual truncation. The
host's already committed memory and adapter effects survive the later failure;
its existing debt remains sticky. The saved-result finish pop uses the original
value primitive. Each pinned fixture establishes the current decoded instruction
from the actual retained pin before effects and PC advance.

The old frame removal helper and rollback/drain callers, completion clear,
cache release/abandonment/build rollback/eviction/cleanup, pending-growth release,
consuming State cleanup, partial construction, refund and construction-phase
cleanup retain the old cursorless route. Old cleanup errors still have stage
Cleanup, absent function/offset/resource and zero attempted/limit. A stale
stored invocation cursor does not authorize attribution on those paths.

There is no new owner, ticket, owner field, completion slot, heap allocation,
public route, authority, check boundary or work/fuel debit. Original owners and
all 329 preexisting concrete type declarations remain exact. Test injection
uses finite additional values of the existing unit `Hooks` byte, with no new
selector field or production hook. It drains the original live count so the
following original subtraction rejects; it does not fabricate an error.

The direct numeric leaf has no frame debt field. The numeric fixture therefore
asserts the original distinction: addition leaves a result and cleanup observes
an arena/count mismatch; trapping division consumes both operands and leaves
matching empty inventories. Both preserve the exact independent invariant and
first failure. Saved-result finish pop also preserves its original early return
and pin retention. No new debt latch is introduced to change those algorithms.

## Review and limits

Root must reconstruct the candidate from the accepted archive and exact patch,
review each contextual/cursorless choice, and obtain independent compiler,
layout and behavior replay before integration. Independent review must include a
different actual pinned body/offset and nested frame, immutable full diagnostic
comparisons and final positive-role replay. This producer packet does not
replace that review.

This is a private macOS host slice. A Wasm offset is not an original Swift
source location. Readable Swift stacks, original source maps, module IDs,
sanitized effect traces, debugger transport, complete calls/dispatch/Swift,
Ready/public invocation, native joins, immutable published FieldLog from a
separate repository, physical phones, signing/store/customer/operational and GA
acceptance remain open. No simulator, emulator, native UI or physical device was
used or discovered. Phones remain disconnected and deferred. No live VM,
tracker, other lane, Git state or external service was modified by this lane.
All 239 owned command groups ended without survivors. The recorded scratch
identity had no open holders immediately before removal; 20,069 files /
12,346,037,487 bytes of owned sources and targets were removed. Retained source
archives, binaries and receipts remain in the packet.
