These limits must remain explicit when root accepts this slice:

- Runtime configuration sets peer verification, CA roots, SNI and hostname verification; the actual database fixtures use `ssl: false` and a synthetic superuser. No successful Neon TLS handshake, certificate/hostname rejection, production role/grant topology, FORCE RLS or tenant policy was exercised. There are no identity or domain tables in this foundation to qualify.
- Liveness deliberately does not query PostgreSQL or prove migrations, processors, identity or release readiness. A green `/health/live` must never become a customer-facing readiness claim for those services.
- The delayed-job test proves an already-running local BEAM processor can execute scheduled work. It does not prove Cloudflare container wake, absent-process recovery, notification reconnect, Neon failover, stale fencing, lost leases, real signer/build effects or exactly-once external execution.
- Queue concurrency is per processor replica. Global tenant quotas/admission, real workers, authorization and privilege separation must arrive in subsequent owned slices. The test `ProbeWorker` exists only in the test compilation path and writes only the synthetic fixture table.
- Package/runtime versions are pinned in source/lockfiles. The independent run reused the existing pinned dependency sources and built in a fresh scratch path, without resolving/updating packages. This does not verify a clean external CI image, production OCI image, license inventory completeness or cross-platform deployment.
- Candidate-2's collector lacked subprocess timeouts and only attempted shutdown after its successful-start flag was set. The subsequently inspected candidate-5 collector adds command timeouts, attempts shutdown when the owned postmaster PID exists, routes/disables generated crash dumps and records its own successful cleanup. This was a harness follow-up, not a failure of the observed successful candidate-2 cleanup. Candidate-5 has its own receipt; I did not independently inject startup/timeout failures into that collector.
