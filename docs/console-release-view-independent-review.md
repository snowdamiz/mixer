The coordinating agent moved wrapper validation inside the guarded memo and rejects null, undefined, and unknown discriminants. Final `console/src/components/ReleaseChecks.tsx:47`–`55` handles these inputs through the invalid-data view. The independent malformed-data test includes those three wrappers plus seven malformed ready payloads. No passing summary, selected revision, or target table appears in any of them.
2. **First theme block did not represent the website's effective palette.** Initially, `brand.css` copied the first website `:root` block, missing the later refinement at `website/src/styles.css:17`. The coordinating agent now preserves both blocks in order at `console/src/brand.css:2` and `:4`, updates the document theme color, and matches the final desktop wordmark size. The independent build check merges the website's root token declarations in order and compares every custom property. It also compares logo/favicon bytes. These checks pass for the final digest.
