memory growth and passes its bounded H01–H16 host development checks. It is
frozen for independent root review and is not integrated into the live VM.

and indirect calls, the complete fetch/dispatch loop, Ready/public invocation,

The operation borrows the original phase, State value/memory arenas, control,
cache and AccountedWasi. It selects only the sealed ordered import descriptor
and checks its complete signature. Parameter work precedes the checked argument
base and full ordered type checks. All signature/frame/cache views end before
actual `AccountedWasi::dispatch`; its existing host-entry boundary supplies the
sole host debit. The adapter remains the sole WASI meter. Errors and unsigned
GuestExit codes preserve the first cause before the postcheck. Successful errno
alone removes arguments once, reconciles the live count, and uses the existing
value push path. A failed reconciliation sets the existing sticky debt flag.
The original fixed `FrameOperationStorage.entry` remains the sole outcome.

The pinned wrapper copies one instruction through the actual caller pin, ends
that view, records the cursor, charges instruction/fuel and caller work once,
and checked-increments PC once. It accepts only an imported `Call`; it supplies
no instruction loop. The fixed completion wrapper delegates the original
completion rule and consumes actual fixed storage. Its fixtures use plain
`prepare_frames`. A future combined growth/host dispatcher must use the growth
completion rule while growth context, storage or debt remains.
