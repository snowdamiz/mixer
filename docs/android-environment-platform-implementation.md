SDK<36 admission guards and does not enable API28–35 rendering or public V2.

`NativeEnvironmentPlatformV2` supplies immutable availability-bearing public
observations. Only `KNOWN` carries a value. An unavailable API, unavailable exact
semantics, undefined source or failed read carries no value. `READ_FAILED`
separately retains the original `RuntimeException` for diagnostic and existing
admission failure routing. The real observer rethrows that exact failure when
consuming a failed observation; `Error`/linkage failures propagate directly.
Neither diagnostic data nor its constructors can mint a native capture.

The base and observer signatures, fields, initializers and emitted constant pools
contain no later-API listener, inset type/query, font-adjustment member or contrast
read. Separately emitted guarded `Api30`, `Api31`, `Api34` and `Api36` classes own
those operations. Pre30 exact `systemBars | displayCutout` semantics are unavailable;
legacy insets are not treated as equivalent. Read-only snapshots on SDK28–35
subscribe to nothing and create no readiness, owner, capture or session authority.

Admission requires explicit night YES/NO, resolved LTR/RTL, the actual first locale
under the existing bounded well-formed Unicode/non-control rules (including
`und`), actual finite bounded density and SP/DIP body conversion, the twelve
unchanged anchors/ties-up selection, exact typed insets, known zero font adjustment,
finite in-range exact-zero contrast, known false high contrast, and a nondefaulting
finite nonnegative animator read. Missing or nonnumeric animator settings remain
undefined; permission/runtime failures remain failed reads. Known zero motion is
preserved as reduced motion. Exact window insets intersect the actual root once.

mint. Both manager/listener/executor handles exist before registration starts.
Their add/remove calls use the retained exact manager, listener and executor;
reentry and throwing adds retain the existing uncertain-ownership ledger and

Owner, core, coordinator, renderer/views, descriptor/wires, JNI, Swift and public
