# Android authored toggle input integration

The live authored V2 Android carrier now uses the three exact production sources
qualified by the private emulator fixtures. Horizontal dragging follows the
authored thumb geometry; releasing on a changed side proposes once through the
existing native checked listener. Rebinding, disabling, retirement and scroll
cancellation clear preview and ownership. Native keyboard pressed state survives
its DOWN/UP pair. The ordinary public application path still uses its existing
platform-default presentation; this slice does not complete shared design parity.

The accepted API37 arm64 evidence comprises the original 20-action coordinator
matrix with 429 assertions, plus all 45 component cases with 213 original and
26 setup assertions. Keyboard setup uses public directional input, observes the
actual transition out of touch mode and verifies an ordinary Button focus control
before requesting toggle focus. It does not alter production focus policy.

The native component export passed, but its original host collector rejected
the serializer's `sequence` field. That failed collection is retained. A separate
reviewed collector requires the exact integer, zero-origin, contiguous sequence
field in both native trace arrays. All original assertions and strict keyboard
predicates remain unchanged. The independent replay passes 269 checks, including
160 rejection controls; the prior 39-case native failure remains a failure.

Root checked the original live hashes before copying only
`AuthoredToggleInputV2.java`, `NativeAppearanceViewsV2.java` and `NativeRenderer.java`.
All 89 product inputs now match the native-tested candidate. A compositional
rebuild of the three live Java families and original fixture reproduces all 163
class artifacts and complete DEX bytes exactly. The 33 producer policy tests and
3,556 independent assertions pass. Unchanged classes come from the verified
earlier archive; this is not a fresh compilation of every source or a new native
run. Tool versions, source hashes, commands and output are retained in the
[integration receipt](../verification/android-authored-toggle-integration/acceptance.json).

The native emulator and its command groups stopped, both owned ports closed,
and 188 extracted files totaling 173,064,117 bytes were removed. The integration
build removed another 167 scratch files totaling 878,770 bytes. Four actual preview
screenshots show the authored track/thumb and mirrored RTL placement; they do not
qualify quantitative Apple parity or every intermediate compositor frame.

Public V2 routing, full appearance parity, renderer authority beyond the private
fixtures, TalkBack, final physical-phone tests, immutable external FieldLog release
consumption and GA remain pending. Physical phones remain disconnected.
