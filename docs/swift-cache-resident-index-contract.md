# Private Swift resident index contract

The measured full target spends 12,346,190 of 64,000,000 cache credits on resident linear lookup. Root selects a bounded private Swift index candidate to reduce that actual work while keeping the 64-entry capacity, LRU order, decoded IR, pin/generation safety, failure behavior and every existing memory/work/deadline limit. This does not predict target completion and does not address all repeated-decoding cost.

Use 128 bucket heads and 64 next links, encoded as slot-plus-one bytes with zero empty, in exactly admitted 192-byte storage. Account the real buffer/header/ticket overhead in fixed reservations. Keys remain the actual resident function identity; the index is not authority. A fixed hash selects a chain, every probe validates the referenced slot/key, and every traversal is bounded by 64 nodes. Invalid slots, links or cycles fail closed. No tombstone rebuild or function-count-sized allocation is introduced.

Shared CacheMode hooks retain literal existing linear lookup and no-op insertion/removal in FrozenMode. Only the private Swift mode overrides them through its scratch/index storage. Meter actual hash, initialization, probes, link checks and writes. Precharge the complete link mutation before atomic unlink or index/slot publication; no fallible operation may split publication. Index insertion/removal failures must preserve the original failure and release or retain entry/ticket ownership exactly as required by the existing lifecycle.

Finite actual-cache tests must cover deliberate collisions, head/middle/tail deletion, slot reuse, eviction and all-pinned behavior, every index mutation work boundary, cancellation, construction and consuming cleanup. Preserve a literal legacy trace and run appropriate Swift/shared regressions. The implementation stays in an isolated source copy pending independent review and root integration. No full reactor, native/signed/public execution or budget expansion is selected.
