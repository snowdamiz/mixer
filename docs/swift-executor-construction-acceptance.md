# Accepted private Swift construction slice

Root accepts candidate4's private uninitialized construction and zero-frame
cleanup, with 927 exact source/evidence bindings in
`verification/swift-executor-construction-root-review/acceptance.json`.
The original constructor document and all failed/superseded receipts remain
unchanged. This document supplies their current acceptance status.

Construction initializes the six fixed State arenas from the retained proof,
composes the original control, cache and WASI owners, and returns only an
Uninitialized reactor. Post-take failures retain authority in a must-use cleanup
tail until the caller consumes every possible-owner return object. Zero-frame
cleanup drops payloads before refunding their reservations and preserves the
first failure and final WASI observation.

Independent review verifies 615 concrete accounting classes, 5,004 named typed
positions and fifteen unit-hook positions across eight actual layout
configurations. Production foundation, additional construction and the same
execution-header bounds are respectively 267,800, 1,062,312 and 207,352 bytes.
These are conservative logical reservations, not physical stack or RSS figures.
The independent lane executed 434 intentionally derived library/probe tests.

The final unmodified archived source passes 366 full host tests per Debug/Release
with nine ordinary tests ignored per mode. Root used a fresh target directory
exclusively for product source, verified all 425 archive inputs before/after each
command, and bound the exact 151-test library binaries and their runtime lists.
The independent reviewer separately verified those binaries and all 35 suite
summaries per profile.

Candidate4's earlier 367-test claims are invalid: its collector reused a target
directory between product and metadata source. The later full runs contained a
metadata probe. Those historical files remain unchanged and are explicitly
superseded by `candidate4-clean/qualification.json` and the independent
`supplemental-product-artifacts/decision.json`. Future collectors use disjoint
fresh targets and runtime test-list checks; the prepared candidate5 collector
was tested with synthetic Cargo fixtures but was not run on the product.

The constructor supplies no interpreter, initialized/Ready reactor, public
constructor, activation or target runner. Shared instruction algorithms,
operation/growth/active-frame cleanup, full Swift target execution and the
specified physical, published FieldLog, signing, store, customer, operational
and GA evidence remain pending.
