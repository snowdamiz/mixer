The detailed oracle is `host-obligations.json`. Each group must name actual
production methods/classes executed, platform-leaf hook and phase, assertions,

  target gets its TextView's current buffer at close. Nested creation must refuse

  exact postconditions pass. Stale close cannot touch a successor.

  visibility, aggregate visibility and public detach before a later hidden
  TextView suffix, while getters remain stale. Public-hook return does not clear
  loss latches. Unknown retired suffix callbacks fail closed with uncertainty.
* On plain native delegate/widget/super throw with no previous revoke, observe
  failure before cleanup, retire permanently and make one eligible known-target
  close. First fatal identity wins over later ordinary/fatal cleanup failures.
  Inaccessible creator target is FAILED_UNCERTAIN; no fabricated target/close.

* Keep configured Done and ordinary text/composition/delete/selection/read paths

## Tool, leaf and cleanup boundaries

Current canonical concrete leaves are intentionally insufficient as-is: the
InputConnection interface has 26 descriptors; EditorInfo has only two scalar
fields; View.hostDetach clears attachment before public detach and lacks the
window/aggregate/public/hidden order. Expanded leaves must be reviewed against
the selected pinned official source shape. Host EditorInfo private payload
semantics are an authored test oracle, not execution of Android EditorInfo.

Use explicit JDK25 Java/javac/javap paths and exact official SDK36/37 jar hashes
from the selected packet. Record command, tool version, source/leaf digest,
stdout/stderr/exit, scope and process disposition. Use bounded child timeouts and
terminate only exact owned children on timeout. No broad process inventory,
computer use, screen capture, UI, simulator, emulator or device run is permitted.
Do not invoke build scripts that launch those surfaces. No Git mutation/delivery,
canonical/root metadata changes or production/customer/credential action belongs
to this lane. No new dependencies are needed.
