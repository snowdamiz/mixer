active admission review, or frozen admission design. Only the exact root
selection, accepted corrected wire contract, its equations/source roster, and
the accepted source tree were consulted. The producer format model/tests were
not read, imported, or executed. No candidate source or results have been read.

The selected component is a pure Rust serializer. This review cannot accept
operational reservation, work, cancellation/deadline, scope cleanup, File/I/O,
hash/close custody, full workload, canonical integration, native/device,
OTA/signing, FieldLog immutable release, or GA. Original 300000/400000 refusal
evidence retains its original attribution. The complete selected 17-limit host
literal stays unchanged. All native/UI/capture work stays paused.

## Guard, privacy and lifetime compiler obligations

Inspect every changed field/accessor/re-export and constructor. Entry is only
borrow_snapshot_v2(&genuine_guard), returning an opaque non-Clone view whose
references expire with the *borrow of the guard*, not merely its owners. A
consuming cursor cannot be reused through the moved view. next_block takes an
actual &mut [u8;4096], and its opaque returned bytes borrow that particular
array; offset/final observations are immutable. No owned/parts/view/guard
constructor, raw proof/foreign provenance arguments, generic callback/writer,
public mutable source/metadata access, or new guard literal is allowed.

After release generate minimal exact-interface compiler cases, with a matching
positive control for each context and unchanged dependency tree. Run both test
and ordinary-production crate configurations, Debug and optimized, on the
selected aarch64 Apple target. Record rustc path/version, target, flags, complete
diagnostics and exact source digests. Negative cases must fail for the intended
borrow/privacy/type reason; an unrelated error is not evidence.

Required cases:

1. Positive genuine guard -> view -> consuming cursor -> borrowed block; after
   dropping block, same transfer array is reused until final output.
2. Construct view/cursor/block/guard or provenance by literal/parts; raw proof,
   foreign source/provenance, digest/bool, and closure entry attempts refuse.
3. Clone/Copy view or cursor and reuse the moved view; second consumption and
   cursor reset/rewind entry attempts refuse.
4. Return view/cursor/source/metadata/provenance/block bytes beyond guard borrow;
   guard-owner lifetime outliving a shorter guard borrow must not permit escape.
5. Move/drop/mutate guard owners while view/cursor remains used; request mutable
   control during that live borrow; mutate source/metadata; all refuse.
6. Reuse/mutate/drop the actual transfer array or call next_block with it while
   prior block bytes remain used; block bytes cannot escape that array.
7. Pass &[u8], Vec, a different array length, or owned block into next_block;
   the actual [u8;4096] contract must be enforced by the compiler.

Expected diagnostic families are privacy E0451/E0603/E0616, missing method
E0599, trait E0277, argument mismatch E0308, moved value E0382/E0505, and borrow
E0499/E0502/E0506/E0515/E0597, as applicable to each minimal case. Record the
precise selected code per case after syntax adaptation. Do not accept an
arbitrary nonzero compiler exit. No compiler claim is made by this pre-access
packet; rustc was absent from the initial shell PATH.

## Boundedness and streaming obligations

All setup must be fixed-size: one 2560-byte header directly stores directory,
provenance/runtime records and resolved IDs. No source/record pre-scan may hide
inside view creation or cursor construction. Fixed loops may cover the nine
directories, 34 actual enum values, fixed field lists and header zeroing. Record
the *actual* ceilings of every loop/method after source review. Variable source
and record checks belong lazily in next_block and must have a concrete bound.

For each next_block, account output-byte copies, record checks, scalar emission,
section transitions and empty-section skips. Require an explicit progress
invariant and finite ceiling for zero-length sections and any repeated visit to
a partially emitted record. A 4096-byte output cap by itself does not prove the
work cap. Reject rescanning whole prefixes, reading all records on each block,
whole-source hashing, recursive traversal without bound, capacity-driven scans,
or reading unused Vec capacity. Header creation must not copy all source bytes.

On a fresh actual cursor, verify offset 0, monotonically contiguous offsets,
full 4096-byte nonfinal blocks across section boundaries, exact final prefix and
final flag, exact ceil(total/4096) blocks, no empty interior output or trailer,
and explicitly specified post-final/error behavior. No reset/rewind/retry by
reconstructing owners. Compare partial-boundary metadata records and source
first/last bytes, with output buffers prefilled by distinctive sentinels; only
the returned borrowed prefix is output. Do not rely on zero-filled test arrays.

The encoder has no filesystem/I/O/callback dependencies or effects, no work/stop
grant input, no independent ledger, no whole-output Vec, no unsafe raw-layout or
pointer serialization, no formatter/Debug-based encoding, and no hidden static
or thread-local output storage. A syntax scan may locate concerns but is not the
review/authority decision. Source review, compiler evidence and actual guard
observations are all required.

## Layout and source-place review obligations

Before assigning any operational budget, measure every new view/cursor/block,
inventory/record/error/result/option/tuple/array wrapper in actual unit and
ordinary-production Debug/optimized builds. Include size and alignment and bind

returning a header/provenance/runtime aggregate creates a separate named source
place even if optimization eliminates a copy. Header creation/return, cursor
conversion and block-return/error moves must be visible in the roster.

Trace each actual source expression, not only struct declarations: accessor
returns, references, fixed arrays, scalar tuples, iterators/closures, match and
Result temporaries, copy/move ingress and returns, caller-owned array, cursor
and view returns, borrowed block/result ingress and returns, error paths and
all simultaneous retained values. Enumerate which exact source place exists
before/during/after conversion and block production. Compare baseline and delta;
an old 201-entry table and optimization do not admit these new places. A layout
sum is evidence for later admission, not granted storage or RSS measurement.

This pure component does not need to modify original outcome payloads or shared
construction/work/stop/cleanup accounting. Verify the sole inline hook is gated
cfg(test/owned host), immediately after the existing sole guard literal and
before original header/row emission. It may observe; it may not mint a guard,
reenter construction, change the original 8-outcome enum, silently alter budgets,
or change existing literal/ordering. Complete admission remains another scope.
