fixture from this review's actual copied-Swift default output. No product code was
changed to pass a control, and no failed attempt is counted as a product pass.

(`swiftlang-6.4.0.34.1`, host arm64 macOS), Python 3.14.8 and official Java/Javac
25.0.4.1. Actual raw inspection also inventories the installed official Android
