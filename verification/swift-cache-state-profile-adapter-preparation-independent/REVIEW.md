# Independent profile-row preparation review

The narrow row/body contract is ready for root implementation selection **with
the frozen protocol amendment**. This accepts a contract, not implementation,
real profile binding, a compiler target or a product/GA gate.

The smallest useful next dependency is immutable function-row provenance from
the actual sealed `ValidatedSwiftReactor`. Its crate-private
`execution_function(absolute)` already supplies absolute index, validated type,
absolute original body offset and an immutable body borrow. Imports return None.
Using that seam avoids a new parser, pointer arithmetic, body copying or an
externally implemented owner-replacement trait. The row body can be implemented
before real profile-header/cache-construction and original-result/custody work.

All 67 preparation members/1,660,679 bytes, 30 input snapshots and 22 exact
excerpts were independently verified. Nine narrowly consulted validator-core
source files also match the accepted completion manifest, including policy,
metadata, reader, validator, descriptors and accounting. The live borrowed cache,

The row fields correctly match the existing 32-byte little-endian parser.
Import/unused sentinels are exact; the body is 2,560,000 bytes and a later
512-byte synthetic header makes 2,560,512. The fixed ABI has 34 imports, function

not compiled boundary receipts. Any maximum fixture that the real validator
cannot admit remains untested; a fabricated proof cannot close that gate.

Two original preparation findings required a bounded protocol amendment:

1. The original buffer upper bound and deferred error definitions did not freeze
   per-file attempt limits or independent error-coordinate expectations. A
   32-byte block and a65,536-byte block both satisfied the original wording but
   implied80,000 versus40 blocks. Root's amendment freezes4,096 bytes/128 rows,
   625 blocks,32 calls per block and20,000 per file; exact codes1–13/stages1–5;
   every actual call counted; only valid acknowledged counts advance bytes;
   complete32nd call succeeds, incomplete/Interrupted32nd exhausts without a33rd,
   while ordinary error/zero/overreport keeps its specific code. Standalone row
   errors have0/0 output coordinates; writer-propagated row errors keep their row
   offset and attach current global acknowledged bytes/attempts.
2. The original `rows_` Cargo filter did not guarantee execution of writer,
   actual-File and layout obligations. The amendment requires a complete frozen
   selected-method namespace/roster and bridge-invocation roster in both modes,
   compiler listings, exact passed/ignored/filtered counts and refusal of empty,
   missing, extra, duplicated or ignored credit. Models and syntax inspection
   cannot replace actual-source and actual-File tests.
