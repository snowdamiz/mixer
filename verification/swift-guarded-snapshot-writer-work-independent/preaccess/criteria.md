Encoder initialization and accepted per-block terms remain separate from caller overhead. All errors abort the whole writer invocation; only Interrupted native writes retry, within the same fixed 32-attempt block loop.

For each attempted block there is one transfer.fill(0), so fill bytes <=4096B. Admitted phase storage separately initializes [0;4096] once; this is not the encoder's already counted initialization. At most 32 attempts per block gives A<=32B. Positive short writes can reach the same ceiling as Interrupted attempts; a 32nd partial positive write returns Attempts without trying a 33rd. Acknowledged positive bytes are recorded before a post-write cancellation/error report. Zero/overreported/non-Interrupted errors abort immediately. No flush, sync, truncate, native operation retry outside the attempt loop, or terminal encoder read is silently added.
