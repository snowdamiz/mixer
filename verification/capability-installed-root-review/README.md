client. The client checks all39 origin and14 namespace cases shared with the
signed Go/Swift protocol corpus through installed material inputs, including
baseline fingerprint identity and absence of container creation.

UTF-8 prefix before hashing/concatenation; owner regressions cover the boundary,

public binary, final source/evidence manifests and official SDK module/object
artifacts. It requires the local retained qualification directories. Compiler and
test commands are recorded in the owner receipts and `compile-command.json`.

This is material admission only. It does not create an adapter, session, task,
directory, startup selection or execution authority. Mobile execution, complete
build graph attestation and signed durable activation remain unqualified.
