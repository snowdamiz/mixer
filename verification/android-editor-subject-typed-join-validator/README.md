# Editor subject typed joins

This bounded host utility freezes all **103** exact `NativeEditorConnectionV2`
subjects from the released 280-subject semantic roster: Base 70, Api31 8, Api33 16,
Api34 7 and top-level 2. Every original category and required case remains in
`policy.json`. All 189 historical IDs remain, with the exact nine editor
replacement tuples and the separate out-of-scope `NativeField.drain` close link.

`build_policy.py` verifies released seal/member identities, all 16 product sources
and all 209 selected run-3 classes before producing the immutable policy. Source
branches distinguish public adapters, proposal/bounds guards, inner exact-overload
native suppliers, outer supplier bridges, pure any-thread `getHandler`, constant
unsupported operations, unsupported executor/body callbacks, constructors/factory,
and pending field-helper/close obligations. The policy is source-derived; none of
these mappings is observed runtime behavior.

`typed_join.py` exports `load_policy`, `normalize_rows(document)` and
`validate_rows(policy, document)`. It pins the policy SHA-256 in code. A normalized
document has schema `mixer-editor-typed-rows-v1`, encoding `raw` or `compact`, a
policy digest, a context header and rows. Raw rows are dictionaries. Compact rows
are arrays with a unique `columns` roster containing the same seven fields:

```
subject_id, case_id, state_id, invocation, association, observations, evidence
```

`case_id` is an original retained semantic case or `$state` for the canonical
seven callback states. Only the explicit adapter maps producer `current` to
`clean`. Legacy successor/fatal states receive no invented canonical alias.
Canonical `terminal-at-entry`/`dirty-at-entry` mean mutation at an already-entered
native hook: the actual native return may survive and the public postcheck can
return its refusal. Original `terminal-before-entry-refuses` and related cases
have `public-adapter-entry` policy phase, require a separate original case ID and
zero native call. This distinction prevents accidental pre-entry credit from
native-hook-entry rows.

The exact invocation tuple includes caller class, method, JVM descriptor, BCI,
opcode/mnemonic, callee owner/name/descriptor and source/class hashes. Actual
`subject_outcome`, `native_outcome` and `public_outcome` remain distinct. Result
unions support strict booleans, JVM int32, null, void, reference identity plus
snapshot, and exact original exception identity/class/fatal status. The immutable
policy supplies constraints; candidate expected fields and pass/status claims
are rejected. Missing native/body/origin outcomes and ancestor-only associations
stay pending. Unsupported executor callback bodies, constructor/factory facts,
and field-helper outcomes remain pending until dedicated actual observations
and source-specific review exist; the current validator does not declare those
cases satisfied.

The header pins product context, source-map digest, class-map digest and a
separate execution-closure identity claim. **There is no trusted execution-source
closure in this packet.** A supplied closure hash grants no authority. Even a
typed-consistent row remains pending evidence review, and every result has
`qualified: false`. The result lists missing subjects; it never collapses sparse
rows into full-matrix completion. This utility accepts future fresh normalized
raw/compact rows without changing the policy, but runtime outcome review and
the exact source-closure review remain separate work.

Run host checks from this directory:

```
PYTHONDONTWRITEBYTECODE=1 python3 test_typed_join.py
PYTHONDONTWRITEBYTECODE=1 python3 typed_join.py validate --rows <rows.json>
PYTHONDONTWRITEBYTECODE=1 python3 example_adapter.py
PYTHONDONTWRITEBYTECODE=1 python3 review_delegated_association.py
```

`example_adapter.py` reads only four sealed one-attribute example files. Each
raw/compact representation yields 18 joins: nine consistent public checks,
seven supplier ancestor-only pending rows and two missing exact native exception
outcomes. Producer and standalone replay both retain this boundary. No lambda
body return is copied from an ancestor, native value or public return.

`delegated-association-review.json` reviews frozen Java `Trace.outcomeEvent`,
`OutcomeCapture`, `NativeOutcomeProbe` and `EventJoinControls`, plus the small
Python pair helper. The source recorder enforces one exact `(II)Z` to
`(II,TextAttribute)Z` delegated return association. The pair-only Python helper is
not a generic hostile-record validator: five coherent metadata/raw-stream
mutations pass its limited checks. The independent bounded raw join refuses all
nine reviewed mutations by binding actual event/frame/authority and the clean
public result. This finding does not allege the recorder accepted those mutations
or grant an unreviewed active auditor credit. Nonnormal states with missing
observations remain pending rather than receiving automatic pair credit.

No product engine, canonical index, Git state or frozen producer file is changed.
No JVM, simulator, emulator, device, UI, capture, process inventory, forbidden
hosted inspector or stopped v5 experiment is started. Full policy matrix,
execution closure, native, OTA and GA qualification remain pending.
