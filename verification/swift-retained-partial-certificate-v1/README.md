# Retained partial-certificate source assessment

This packet is an unapproved source-only proposal. It is not a certificate, an
independent semantic review, a trusted root approval, or an invocation plan.

The accepted retained-binding verifier supports unknown congruences, an unknown
outer arena, incomplete frames and unresolved return-pointer links. Its closed
map grammar cannot retain all distinct intermediate physical copy-stage
identities, intervals and lifetimes. Dispatch `%owned`, `%_7`, `%_6` and incoming
C are distinct; Body's setup and loaded payload chains also contain distinct
physical stages. A containing native frame does not establish a complete copy
map. `schema-assessment.json` pins the exact source limitations and describes the
minimal additive stage table. No change to the verifier is included.

`proposed-partial-semantic-map.json` preserves the frozen structured native
slots, complete copy-chain descriptions, actual immutable target spans, signed
instruction coordinates, unresolved Body unwind/termination, all backing
obligations and retained partitions. Its explicit proposal schema is deliberately
incompatible with verifier v1. Known native reservation lifetimes are kept
separate from unknown initialized/value lifetimes at copy micro-stages.

`proposed-input-bindings.json` joins the exact immutable retained observation at
its real field levels and lists future saved-artifact input pins. Raw generated
artifacts, MIR and the 146 source member contents were not read in this metadata
preparation; their inherited pins must be rechecked by any separately selected
invocation. The capture-acceptance envelope is a proposed grammar translation of
already accepted capture custody, pending root selection; its status string
grants no new authority. No independent-seal/review or trusted-approval envelopes
have been invented.

A future explicitly incomplete projection could leave affected return-chain
states `unknown`, which the current source turns into local missing facts and
suppresses every numeric phase result. Such a projection would still need to
state that unsupported stage rows are unrepresented. This packet does not emit
that projection or select an actual invocation. Root can independently assess
whether that limited diagnostic would be meaningful before choosing it.

Physical base congruences, O's arena/relation, all copy stages' value-lifetime
proof, external callee peaks, Body's nonlocal continuation, backing capacity and
final destruction, prices, quote terms, durable root funding, runtime admission,
original-configuration qualification, FieldLog/OTA and GA remain unresolved.
`WholeQuotePending` is preserved. Native tests, UI and capture remain paused;
this preparation starts no native/capture process and owes no runtime cleanup.

The receipt records the bounded stdlib-only command and inherited tool version.
No verifier import/invocation, fact verification, compiler/native/version probe,
test run, process inspection, UI/capture/network action, existing packet edit,
product/global metadata change, commit or push is part of this packet.
