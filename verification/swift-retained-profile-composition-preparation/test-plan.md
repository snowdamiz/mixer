# Finite preparation controls

Run `python3 -B run_evidence.py` from this folder. It copies only named predecessor
documents/selected sources, records Python executable hash/version, platform,
git HEAD/tree and this packet's exact source-tree digest, invokes the closed finite
test command, captures both output streams, records cleanup and seals all members.
No predecessor one-shot script, existing product harness, hosted catalog/authority
tool, native runtime, UI or capture executes. There is no new dependency.

The executable witness uses synthetic constant row-body bytes and fake source/
build/event/layout artifacts. It cannot exercise the authentic Rust guard/exporter
or existing accepted constructor. No schema deserializer can create that owner.
`protocol-types.rs` is a source-private data/signature proposal only, deliberately
uncompiled; no Rust layout, privacy test or runtime charge is claimed for it.

All explicit loops use fixed extents and32 per-block attempts. `budget.json` gives
the conservative full input-cap I/O envelope; healthy observations are smaller.
This is not a proof of Python total heap/RSS, standard-library internals, actual
retry/CPU/all-source-evaluation work, VM debits or elapsed time. Test-only fault
seams do not prove every failure arises from the kernel. Actual safe syscall
faults which cannot be induced, a stuck OS child, and quarantine persistence are
source-reviewed only; do not report them as executed or healthy zero cleanup.
