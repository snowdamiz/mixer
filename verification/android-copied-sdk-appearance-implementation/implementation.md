success. Export re-admits its actual copied sources before its final digest.
Missing/legacy/unknown/mismatched profile records refuse with actionable migration
or matching-distribution instructions. Malformed and unknown profile fields also
refuse. iOS-only selection keeps the previous contract.

The full-UInt64 packet revision uses the public reconciler. Exhaustion-edge
identity generations are supplied through an internal test-only snapshot
constructor to the actual production writer; this does not add a public snapshot
constructor or claim natural counter exhaustion was reached. Swift and Java then
execute their actual encoders/decoders/routing on the preserved bytes.

The initial javac attempt failed because its explicit empty source/class-path
directories had not yet been created; strict warnings rejected those paths. The
attempt and output are preserved, the directories were created, and compilation
and all codec checks then passed. An intermediate Java run overlapped a compile
and is superseded by the separately named qualified compile followed by qualified
execution. No failed or superseded attempt is presented as final qualification.
