## Reviewed behavior

- The sealed ten-recipe family and all retained metadata match Swift. Exact revision and generations survive values above signed 64-bit range, retained identities survive reorder, and a same-ID kind replacement receives the actual reconciler generation. Preorder and child order remain unchanged under RTL.
- Input theme/control/layout/type fields have deliberately distinct values. Four text roles, all button roles, both toggle states, title/header absence versus empty text, all admitted explicit alignments, and descriptor-selected baseline defaults are discriminated. Light/dark, RTL/LTR, shared versus explicitly platform-specific mode, and bundled font/icon metadata are covered.
- Text uses half-up fixed-point scaling once. Double spacing tests include representable neighbors around ties, zero, negative zero and 256. Aggregate height reaches 393216 without truncating to the individual-metric bound. Logical control/layout metrics and child order remain unchanged as density varies.
- All four pressed/focused combinations are checked for every resolved node. Inherited disabled overrides descendant false. Transparent and partially transparent palette colors retain their unpremultiplied alpha with separate opacity; role colors, optional paints, focus outline and canvas are exact.
- Descriptor admission checks the entire closed graph, including unselected palette/platform branches and resource metadata. Malformed schema, canonical spelling, bounds, resources, environment, node properties and revisions fail before a plan is returned. This establishes a data failure boundary only.
- `AppearanceDescriptorV1.decode` owns a cloned byte buffer and builds recursively unmodifiable maps/lists. `UiPacket.decode` builds properties/actions/children/node maps in private local builders; mutable builder aliases do not escape its private outer constructor. Its package-private `Node` constructor alone cannot manufacture an admitted packet. Scalar leaves are immutable. `Plan` copies child ID lists and the final node list; its index builder stays private. Deep runtime probes cover both descriptor branches, resources/faces, every packet node, private plan index/palette, all record graphs, map entries/iterators, lists, and mutation of the original byte arrays. Enabled event bytes remain unchanged and disabled events still reject.

## Open boundaries

The existing `UiPacket` decoder rejects explicit HStack `firstTextBaseline` and `lastTextBaseline`, and nested scrolling lists, while Swift accepts them. These three cases are named in the corpus and counted separately. Descriptor-selected baseline defaults resolve as data; adapter support and coordinated packet widening remain pending. This review neither widens those boundaries nor treats them as parity passes.

`sharedCandidate1` remains a provisional data recipe. Its Apple typography/list/navigation/toggle measurements are under separate review. Product plan §8.3 requires native shared design and physical side-by-side qualification; this review does not approve an exact final iOS appearance on Android. Native widgets, resource bytes and actual font support, aggregate native extent conversion, geometry/raster parity, interaction/accessibility/IME, signed authority, installation/display/health, store/customer/operational review and immutable separately published FieldLog packages remain unverified. All GA gates remain open. Phones are disconnected; this review performed no device discovery/run and made no reconnection request. No product, tracker, credential, customer or publication changes were made by this review lane.

`seal.json` binds every retained non-build file in this review directory. Ephemeral `.build` contents are excluded from the portable seal; their compiled hashes remain recorded in the runtime receipts. No general-purpose dependency was introduced.
