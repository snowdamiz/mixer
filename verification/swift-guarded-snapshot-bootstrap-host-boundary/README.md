it acquires/constructs fixture File owners, invokes the loader, creates the

admission action reserves its complete closed-run bundle in that pre-existing
host account. This function/account is a required next implementation, not an
API present in this packet. Successful process/descriptor/build/session

The account's owner must select and enforce the finite bundle for the exact
one-fixture source/tool/driver manifest. The launcher may dispatch **once** only

selected and tested, **there is no operational grant** and no runtime release.
