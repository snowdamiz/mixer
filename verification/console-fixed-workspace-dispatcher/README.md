# Private fixed workspace dispatcher component

This producer implements only the selected private, same-process dispatcher,
typed request codec and local capture adapter. It adds no production caller,
route, startup, callback, cookie or active-session authority. The canonical
BearerIdentity and CustomerWorkspaceController defaults remain responsible for
current identity, request admission and ordinary workspace storage authorization.

The accepted host attempt is `execution-plan-attempt-3.json`, executed once with
`run_host_tests_attempt_3.py` after root's exact release. It compiled 35 ordinary
and new modules with zero compile/runtime warnings and passed 19 tests with zero
skipped or excluded tests. `host-attempt-3-receipt.json` records command, tools,
source/closure pins, output and cleanup. All 985 original input hashes remained
unchanged, 558 copied files were verified, and exact owned process group 38377
and scratch were absent after the direct child was reaped.

The first two attempts are retained as failures. Attempt 1 passed 18/19 tests;
its only failure inspected exports before loading the compiled dispatcher. The
test now explicitly loads that module before introspection. Attempt 2 stopped
before tests because the harness expected the legacy warning-list result after
requesting modern compiler diagnostics. Pinned primary Elixir 1.20.4 documentation
grounded the corrected strict zero-warning-map pattern; unexpected results now
produce a fixed classification and counts. No product source changed between
attempts. `attempt-1/` and `attempt-2/` seal their original bytes and receipts.

Each frozen execution plan enumerates 29 canonical ordinary sources, six new
product/test files, dependency BEAM/app identities and tool pins. The runners
refuse existing evidence and require a matching root release. The source-only
pin generator and documentation reader use Python standard-library file reads;
they launch no compiler, Mix, BEAM or product code. The host runner starts ExUnit
and a bounded Mix.State process for existing compile-time environment guards,
without starting product, dependency or Mix applications.

Observed host evidence has three explicitly limited scopes:

* Pure typed codec and canonical request admission use labelled synthetic identity
  fixtures, preserving exact organization and canonical cursor bytes.
* Capture/ordinary controller positive pages use a labelled synthetic trusted
  facade through the controller's existing trusted test seam. These do not
  establish real identity, dispatcher success, database state or session readiness.
* Public dispatcher negatives use the actual fixed default ConfiguredVerifier in
  a fresh host VM with no registered KeyOwner or Admission state. They can capture
  canonical 400/503 responses and prove request ID/Repo/mailbox confinement; they
  cannot establish a currently authorized successful workspace request.

Actual default verifier plus ordinary Repo 200, RLS, commits, revocation, expiry,
transaction/context/dynamic binding integration and real-route equivalence remain
pending. Callback Unit A, active-token provenance, provider/OIDC, custody/startup,
cookie/HTTP/log/ingress acceptance, customer workflows, W14/G22 and GA remain
pending. Native/capture and physical-device execution remain paused.

No new dependency, canonical existing product, metadata, workflow or protected
file change is owned by this producer. Root owns independent review, status/gate
updates and delivery. The runner owns only its temporary child process group and
scratch directory, enforces 50 seconds of work plus at most 5 seconds of owned
cleanup and 196608 output bytes, and records exact process-group/scratch absence.
