## Exact one-step caller and fixed outcome

The private bounded caller retains its original function pin, views its actual
cache entry, copies the selected instruction and function, and ends that view
before any effect. It checks fixed-slot vacancy before active/cache/fetch/debit
or PC changes. The admitted decoded Load/Store forms charge one instruction/fuel
and the original one execution-work credit, then checked-advance the actual frame
PC once. The helper adds neither instruction fuel nor PC movement.

Every early active/cache/missing-instruction, charging, checked-PC or helper error
now goes through the actual `FrameOperationStorage.entry`, requests the existing
terminal/deepest-first drain, and preserves the original first failure. Outer
`Ok(())` means only that the inner result was published. An occupied success or
failure is preserved by both caller and helper admission. No next fetch can occur
until the caller takes the previous successful result; a failed result remains
for original fixed completion and cleanup.

The fixtures distinguish cancellation before instruction charging from a
cancellation triggered at caller work after that charge: the latter retains
instruction/fuel +1, work +0, unchanged PC/value/memory/pins, actual stored
`Cancelled`, and terminal/draining state. Helper cancellation and work denial
record the actual pop/width/push prefix. Stores have no partial memory write.

The actual original ABI fixture validates and constructs a real 584-page memory
and original table/cache/control/WASI/state owners. Finite cases use at most 64
fixture instances per case, 64 counted helper attempts per fixture and three
frames; execution is serial. No iOS/Android simulator, emulator, physical phone or UI runtime
is used. Existing test scaffolds are exposed only by visibility changes. The
original push-room/live-admission and cancellation hooks wrap the actual accepted
push primitive, and an isolated test-only PC-overflow hook exercises the actual
checked-PC error. Those runtime call-site types are positively accounted.
