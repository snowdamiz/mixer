# Independent actual-source review plan

This is a preaccess plan, not implementation acceptance. The selected input
identities are in `input-custody.json` and `compiler-amendment-custody.json`.
The active producer directory has not been read, listed, hashed or executed.
Implementation-specific method names, source closure, exact compiler commands,
budgets, layouts and caller lifetimes remain deliberately unbound until root
releases frozen bytes. A failed or unbound prerequisite gives no runtime credit.

## Actual owner and rows

Use the real copied VM crate, its unchanged selected validator and constructor,
and its actual `ValidatedSwiftReactor`. Freeze every dependency read by that
crate and compare the selected validation core identities before compiling.
Cache/control drift disclosed by the selection does not inherit acceptance.
No replacement owner, public constructor, trait substitute, manually populated
metadata, altered admission policy or fabricated descriptor can count as a row
test. A test-only module in an independent copy needs root release of its exact
base/suffix hashes before execution; it must not alter the frozen producer.

The three independently encoded positive candidates cover minimal fixed ABI,
distinct equal-content body offsets, multibyte function/type/body LEBs, body
lengths 127/128, and the 80,000 total-function boundary. Run actual validation
first and retain the result. If the maximum candidate refuses, preserve that
failure, identify the actual policy limit and narrow boundary credit; do not
alter caps or fabricate its owner. The five refusal candidates must produce no
owner and no adapter output. Their refusal is validator evidence, not adapter
error coverage. No Python framing check substitutes for actual validation.

For each accepted candidate, compare all 80,000 actual rows against the frozen
independent bytes. Check imported rows 0..33, first defined row 34, exported
entry 62, exact last defined row, undefined tail, and 79,999 explicitly. Compare
every little-endian field and reserved zero, rather than a digest alone. The
minimal candidate's equal bodies at distinct source offsets must stay distinct.
The wider candidate's absolute call 128, types 128 and lengths 127/128 must use
the source byte coordinates, not code-section-relative offsets or inferred
instruction lengths. An accepted snapshot must remain unchanged after repeated
row requests, successful writes and failed writes.

Request rows 80,000 and u32::MAX from an actual valid snapshot: code 2, stage 2,
offsets 2,560,000 and 137,438,953,440, output counters zero. Widen before multiply.
For codes 1, 3, 4 and some code-13 branches, first establish whether the selected
sealed constructor can construct the fault. Where it cannot, document the
constructor invariant and exact defensive source path. Refused Wasm is not a
license to fabricate an inconsistent snapshot or claim that branch executed.
If a row error is reachable inside writing, its row coordinate must survive
while the writer attaches the global acknowledged bytes and attempts.

## Actual File and writer faults

`writer-cases.json` freezes 29 separate protocol expectations. Apply every
reachable schedule to the actual private write loop through the narrowest
test-only seam authorized by the selected source, and keep its same block loop,
counter updates and error constructors. A separate lookalike writer is not
coverage. The schedules demand no 33rd call, specific error precedence on call
32, and successful completion on call 32. Each callback counts before invocation.
The file maximum is 20,000 calls, including Interrupted and ordinary faults;
only valid acknowledged counts increase output_bytes. A future actual callback
must record requested remainder, local/global attempt and byte coordinates.
Check the whole bounded trace against the oracle, including that forbidden
sentinel actions are never called. Protocol trace hashes are supporting joins,
not replacements for counter/error assertions.

Use independently owned quiescent regular Files, without descriptor adoption,
unsafe ownership, concurrent aliases or unrelated paths:

| Case | Required actual result |
| --- | --- |
| Empty regular File at offset zero | Full 2,560,000 bytes; exact independent body and observation |
| Prefilled File, seek to zero | Code 8/stage 3/offset 0/counters 0; bytes unchanged |
| Empty File, seek to one | Code 8/stage 3/offset 0/counters 0; length/content unchanged |
| Owned directory safely opened as File | Code 6/stage 3/counters 0 when the host supports this File operation |
| Read-only regular empty File | Admission succeeds, first actual write fails code 9/stage 4/offset 0/bytes 0/attempts 1 |
| Valid prefix followed by injected ordinary error/zero/overreport | Exact codes 9/10/11 and counters; independently read retained physical bytes |
| Completion or fault after earlier complete blocks | Preserve global, not block-local, cursor/attempts |
| Deliberate side effect followed by Err/overreport | Acknowledged cursor does not claim rollback; physical script checked separately |

On every actual positive, read back the File through the retained safe handle,
compare length and every byte to the independent oracle, and record its digest.
On forwarding fault schedules, compare retained physical bytes independently.
For dishonest errors/overreports, only the explicit side-effect script predicts
the physical bytes; never infer those bytes from the acknowledgement counter.
These controls do not characterize normal File writes as adversarial.
No fsync, flush, reopen, truncate, finish syscall, durable artifact, immutable
custody or post-fault physical-state guarantee is added by success counters.

Metadata-query failure (5) and position-query failure (7) need applicability
review. A safely opened, retained ordinary File may not expose these faults
deterministically. If privately injected, label that evidence separately from
actual File admission. Never close or forge an owned descriptor to force them.
Record host-inapplicable directory behavior as unrun, not passed. Any public
File error must have its precise selected numeric fields, not merely Err.

## Complete method and bridge rosters

Before actual qualification, bind every requirement in `review-roster.json` to
the frozen compiler-listed fully qualified method names or an explicitly
unreachable defensive-source proof. Freeze the entire selected namespace,
including layout/File/fault/owner tests; a rows_-only filter is forbidden.
Compare the complete compiler inventory in each mode. Reject empty, missing,
extra, duplicate, ignored or multiply credited names. Execute each selected
name in Debug and optimized builds; verify exact passed/failed/ignored/filtered
counts against that build's full compiler listing. Any explicit partition must
cover the same frozen roster once and preserve previous timeouts. Do not claim
performance equivalence between a partition and a failed single invocation.

The bridge has a separate fixed invocation inventory in both modes. For each
positive, row-body bytes must originate from the actual validated-owner writer
artifact whose compiler/source/mode/source-Wasm identities are retained. Compare
them against this packet's independent oracle before passing them to the
unchanged fixture analyzer. A context/header/profile built for a small module
is synthetic; real body provenance does not establish a real compiler's header,
layout or configuration binding. All authority getters must remain literally
false for positive and negative analyzer observations.

Bridge negatives must be applicable to the consumer being exercised: alter
defined/type/body_offset/body_len/reserved or imported/tail sentinel fields
separately; pair body-semantic mutations with actual body-bearing stream records
where that phase performs the join. Equal-content bodies at different source
offsets must fail identity substitution. An in-range row mutation in a phase
that never consumes body identity cannot honestly be expected to fail that join.
Recompute framing/digest echoes where needed to reach the semantic check.
Collusively changing both a synthetic row and event does not prove source-bound
rejection; compare to the actual immutable owner rows independently. Keep
Failure14 unavailable, CAP unknown-tail behavior, late footer/drift/output fault
observations and outer File errors separate. Never promote these fixture cases
to original typed result/ledger, hash/CLI custody, runtime or GA acceptance.

Compile exactly the unchanged three-source fixture library closure from the
selected canonical pack. Per the additive compiler amendment, its non-test
library command has --edition=2021, explicit crate name, --crate-type=lib,
Debug or -O and owned output, and neither -Dwarnings nor -Awarnings. Retain and
inventory normal diagnostics by code/kind/source. The root's inherited 148-
warning strict-command failure remains a failure; it is not rerun as a pass.
The new adapter and new bridge retain their selected strict warning policy.
Review exact arguments and environment in both modes. No blanket suppression
or inherited-library exception extends to new source.

## Source, layout, work and simultaneous lifetime proof

Audit the complete new source and all callers before assigning an allowance.
Use actual compiled size/align of row, observation, error, both full Result
types and any caller aggregates in each mode. Row32/observation64/error32 are
declaration obligations only; do not infer Result size or storage overlap from
them. Count enum tags, success/error places, constructor Result, owner wrapper,
callees, return-value places, moves and caller-held observations. Measured
layouts are not physical stack high-water or allocator/RSS evidence.

Maintain a per-source-place table with bytes, multiplicity, creation, last use,
coexisting places, branch applicability, caller, and evidence. In particular:

* The single 4,096-byte block must be reused for 625 blocks; no 80,000-row vector,
  whole body copy, per-row allocation or second hidden output block is allowed.
* Source body slices borrow the actual owner. No body clones, escaped borrowed
  descriptors or hidden owner/Vec/File/string fields in observations/errors.
* Snapshot retained source and metadata remain under their actual selected
  reservations, but its construction Result and any copies may coexist until
  source proves they end. Count that coexistence or narrow the caller lifetime.
* Count row32, full row Result, error32, full observation Result, observation64,
  writer state and all caller result/ledger places while simultaneously live.
  Rust moves do not automatically authorize additive storage elision.
* Count LE encoding, block zero/init/copy work, every actual row lookup, metadata
  check, arithmetic conversion, attempted write, short/retry/error branch,
  counter update and finish observation, including callees and error paths.
* Review descriptor lookup complexity and work over all 80,000 rows, 625 blocks,
  20,000 writes and actual owner bounds. Instrumentation may confirm the path,
  but synthetic counters alone cannot replace complete source accounting.

The inherited fixture's old 29,344-byte union, G totals and test counts provide
no allowance to these new places. Close the complete fresh proof against the
unchanged caps before acceptance; a passing File output cannot repair a missing
logical-memory/work/caller proof. Do not infer real runtime construction/layout
binding from the actual validator plus a synthetic bridge.

## Later bounded execution and custody

After root release, independently verify every frozen member, copy only the
selected closure into this lane and record exact base/derivative identities.
Review new scripts before execution. Freeze compiler identity and each command's
role/arguments, selected roster, global active and cleanup bounds before running.
Use existing approved tools only, no install, alternate fallback or cap increase.
Keep each child within 60 seconds unless root selects a different bounded
contract before execution. Preserve raw failed commands/timeouts and partial
outputs. No duplicate full 103-command old pack is needed for this new seam.

Set TMPDIR/TMP/TEMP and build/cache outputs to owned scratch for every child;
reject parent traversal and foreign paths. Scrub Rust test/flags/wrapper/launcher
injection, use hostile inherited sentinel values as controls, and set no-install
tool selection before launcher execution. End-to-end source and tool hashes,
not HEAD alone, bind the source; Git calls need explicit task authorization.
Retain source, outputs, commands, diagnostics and observations; hash disposable
products before owned cleanup. Preserve recoverable scratch when the terminal
cleanup deadline expires. Do not enumerate processes or run native targets.
