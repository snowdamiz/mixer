# Independent correction review prepared before candidate access

This packet fixes the review criteria before reading the producer's correction.
It reads only the root F1/F2 selection, the frozen original 70-member design,
the frozen original 35-member actual review, and the accepted 144-member source.
`prepare.py` verifies every pinned member before and after its controls. The
active correction and active encoder are not inputs.

The F1 criteria are an independent source-backed branch and lifetime review
plan. They do not execute a new adoption core. In particular, successful drop
of a passed value does not prove that a retained error, Result, return slot,
move, receiver, or caller place has ceased to require its charge. The finite
conservative result permitted by root is an enlarged retained charge plus the
actual cleanup invariant, explicitly unqualified for healthy cleanup.

The new F2 controls isolate the previously untested *refused* ownership branch
and a guard-derived view that survives attempted completion. They use the exact
accepted `InitialProfileScalarsV1` and `InitialProfileBorrowV1` definitions, with
opaque stand-ins for their referenced components. They do not implement Mixer
admission, inspect, export, headers, rows, tickets, or cleanup. The positive
control demonstrates a possible admitted/refused sum owner feeding one guard;
that private sum type is an independent language control, not a selected
producer contract. The negative Option fallback is rejected with E0502, and the
view crossing completion is rejected with E0505. These add refusal/view coverage
without replaying the prior direct-conflict/admitted-feasibility controls.

`acceptance-criteria.json` is the precommitted oracle for a later frozen candidate
review. Passing these small controls, measuring types, or a source inventory by
itself cannot accept the corrected design, an operational grant, a complete
floor, an exporter/writer, native behavior, FieldLog dogfood, or a GA gate.

No canonical/frozen source, metadata, budget, RuntimeControl field, alternate
finish floor, or other lane is changed. Root owns delivery and metadata. No
native/device/simulator/emulator/UI/capture/process inventory is performed.
Temporary compiler outputs are created only under this packet and removed.
