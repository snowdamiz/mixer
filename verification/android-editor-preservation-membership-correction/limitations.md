# Scope and pending evidence

This frozen candidate is ready for independent actual-source review only.
No independent acceptance is inferred from producer host/bytecode evidence.

The selected controls use host Java with controlled authored Android/JNI leaves.
They prove bounded source/host invariants; they do not establish ordinary
reachability of private corruption, public exploitation, Android framework,
ART, IME, EditorInfo/batch, accessibility/TalkBack, hidden/detach or OEM behavior.
Constructor-owned final journal/position and final captured member identities are
source premises, not a guarantee against arbitrary reflection/Unsafe mutation
of those premises. Asynchronous interruption during scalar writes is not claimed
recoverable. Allocation failure at the new membership allocation is analyzed in
source/bytecode; no new runtime fault hook was introduced at that instruction.

Existing uninstrumented selection getters still lack individual host callback
probes. Existing adversarial Editable controls remain host models. Both original
SDK36 admission guards remain unchanged; unsigned SDK37/D8 min-api28 compilation
neither admits API28–35 nor supplies native ART qualification.

Computer use, screen capture and native simulator/emulator/device runs remain
paused. None were started, queried or inventoried. All deliberate malformed
custody remains busy inside its host JVM until the bounded JVM terminates;
termination is not a native reclamation receipt. Other projects' processes and
data were not touched.

Canonical/source-pair/CLI integration, public V2 routing, native/physical final
acceptance, signing/store, immutable published packages consumed by FieldLog in a
separate repository, production operation, OTA release and GA remain unaccepted.
No dependency, SDK/platform, product cap, timeout, authority or hosted contract is
changed. Root owns subsequent selection/integration and accountable gate review.
