# Additive descriptor consistency utility

This ordinary-host Python utility composes the root-accepted frozen v3 raw/compact
and receiver-consistency facets. It streams only the214 manifest-named compact
files once for new descriptor facets. It does not replay the original225-file
auditor, launch Java, execute product code, or collect native evidence.

`public-contract-investigation.json` records all38 exact public descriptors and
their compiled concrete editor declarations, the20 direct and7 query source
dispatches, and the direct-close dispatch. Each observed public outcome is checked
against its own exact descriptor. Native outcomes are checked independently;
public refusal/null and an observed native snapshot can both be valid.

Each selected completion retains the symbolic compiled caller, method descriptor,
BCI, opcode and callee tuple. The observed receiver is separately checked against
the retained hierarchy and resolved compiled override. This is consistency of
recorded data and compiled declarations, not unobserved runtime dispatch evidence.
Only the root-selected exact composing-attributes caller/outer descriptor/receiver/
resolved override/inner descriptor pair receives the already-accepted delegation
adapter. Hook exceptions retain their original identity and leave normal body
results pending. Missing844 completion rows remain missing.

Reference assignability uses exact nominal equality or retained compiled superclass
and interface edges. Only two additional nominal edges are enabled: String to
CharSequence and String to Object, from the root-approved official JavaSE17
declaration in `spec/string-java-se17.json`. Its retrieval time, URL and source
content hash are retained. This specification does not prove host execution
closure. Other absent hierarchies and array-covariance rules remain unresolved.

The output retains the original280 subject records,2705 required cases and189
historical binding records without changing their qualification status. Finite
facets never qualify a whole subject. All semantic/helper/enclosing/allocation,
runtime/compiler/device/store/operational, OTA and GA gates remain separately
pending beyond previously accepted finite evidence. Computer use, capture,
native runtime tests and process inventories remain paused.

Preparation: `python3 check_descriptor_joins.py --prepare` validates exact released
source/class/ledger inputs and writes the prepared manifest. The source seal is
then frozen before `python3 run_bounded.py`, which runs the focused tests and the
single compact-row pass as direct ordinary-Python children, each limited to60s.
The receipt records the actual commands, Python version/executable, source seal,
input manifest, stdout/stderr identities and direct-child cleanup. No original
one-shot wrapper or full auditor is imported or executed.

No dependency was added. Python standard-library utilities and the separately
hashed sealed classfile data reader are the only implementation dependencies.
Source and outputs remain pending independent review; there is no publication,
runtime promotion or GA acceptance.
