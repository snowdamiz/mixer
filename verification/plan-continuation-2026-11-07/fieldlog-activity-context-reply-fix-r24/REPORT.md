Closing immediately invalidates that context's pending work and reply; a serialized context close touches the singleton workspace only when it still belongs to that context. Canceled commands cannot activate or publish replies. Closed contexts are removed after teardown, with no tombstone/history collection.

JNISurface carries the originating context through activation/install/revoke. JNI selects that registered receiver independently of the caller pumping MainActor. The registered old receiver remains retained until its exact SDK owner revocation returns; failed revocation prevents context release. Java continues bounded close pumping after destruction so asynchronous repository closure does not depend on another Activity opening. Deferred presentation deliveries also require the same still-live context and exact presentation. Existing SDK owner matching and all public host/surface/CABI contracts remain in force.
