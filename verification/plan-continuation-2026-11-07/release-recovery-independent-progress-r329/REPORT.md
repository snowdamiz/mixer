# R329 updater recovery: executable test-only slice

The existing Go updater passed 15 new real-filesystem fault/reopen cases. No product defect was reproduced; the only proposed change is the new 194-line `services/updater/recovery_commit_test.go`. Canonical sources and policy/index files were not modified. No Git operation, native device, remote mutation, production network, deployment, or production signing key was used.

The matrix injects ENOSPC at before_write, before_file_sync, before_rename, after_rename, and after_directory_sync independently during activation, health promotion, and threshold quarantine. Each case prepares healthy/candidate content through public Begin/Resume/Start/MarkHealthy APIs in a fresh temporary store, observes the injected error, rejects another launch from the uncertain writer, closes it, and reopens the same real store. It asserts the old or new atomic state at the named checkpoint, exact payload bytes, persisted launch binding, health/failure/quarantine state, unchanged state version and sequence, and rejection of a stale signed assignment. Unknown interrupted attempts recover healthy content without fabricated startup failure counts; retired launch health reports are rejected. The two committed-quarantine cases additionally reject a newer signed reassignment of quarantined content, accept a fresh rollback assignment to the healthy artifact, reopen again, preserve quarantine/high-water, and reject rollback sequence reuse.

Validation:

- Baseline existing updater and selected protocol suites: passed, exit 0.
- Initial 15-case new matrix: passed, exit 0; final source later adds two rollback/reopen controls and nil-safe cleanup.
- Final complete copied updater and selected protocol suites with `go test -race -count=1 -timeout=90s -v ./updater ./protocol`: passed, exit 0; updater 5.111s, protocol 2.671s. Canonical release-v1/v2/v3 vector/corpus tests remain passing. These are package test times, not a performance qualification.
- Unified patch dry-run against an empty owned destination: passed. Afterimage hash is in `change-manifest.json`.
- Exact copied canonical inputs were rehashed after testing: no drift. Temporary test/store and build directories were empty; the fresh private compiler cache and empty scratch temporaries were removed. Source snapshot, patch and raw logs are retained.

`commands.json` records exact arguments, working directory, environment, exit code and raw log for each test invocation. `source-inputs.json` identifies all copied inputs and their tree digest; Git was intentionally not used. `tool-versions.txt`, `result.json` and `cleanup.json` contain compact run/cleanup facts. Re-run by recreating the removed private cache/temp paths from commands.json before invoking its final command. No external dependency download is required for these selected packages.

Limitations: injected I/O faults plus orderly close/reopen exercise the actual durable store, but do not emulate an OS kill, actual ENOSPC, filesystem/power loss, or mobile storage semantics. An after_rename observation on this live filesystem does not prove power-loss persistence before directory sync. The Go updater intentionally remains protocol1/guestABI1/UI1 only. Protocol2/3 validation is Go protocol-unit coverage, not Swift/native updater or OTA acceptance. `services/protocol/http_shape_test.go` is excluded from this domain-only copy because it imports the unrelated HTTP release service. Fuzz functions ran their seed corpus only. Independent slice review is for parent coordination; no GA, published-package, physical-phone or release gate is advanced.
