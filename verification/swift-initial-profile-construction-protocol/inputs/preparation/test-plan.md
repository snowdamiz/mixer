Executed here: only `test_design.py`, using frozen inputs, independently encoded
header byte arithmetic and a deliberately transparent mathematical reservation
model. No product Rust is imported/executed, and no design-model pass proves an
actual owner, syscall, compiler layout, debit, File custody or VM behavior.

arbitrary model values, explicitly not an ABI size selection.
