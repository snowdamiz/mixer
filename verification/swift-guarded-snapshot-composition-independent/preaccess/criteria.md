# Independent guarded snapshot composition preaccess

Prepared before access to the active composition tree or its work audit/review.
This packet selects no complete floor, work formula, operational grant or writer
execution. Review starts only after root releases an exact immutable candidate.

Acceptance requires all of the following in the final actual source:

1. **Authentic ingress:** only the private consuming selected capability can
   select Snapshot. Trace its original body, validation provenance, cancellation
   backing, control and tickets through shared admission. Original ABI callers
   select Original structurally. No bool, bytes, digest, foreign ticket, callback
   or test event supplies authority. Retain all primary and retirement failures.
2. **Closed control flow:** preserve original admission order, all eight original
   inline outcomes, original header/row behavior and one actual guard literal.
   Original adapters cannot receive Selected results. Shared access owns the same
   exclusive control in admitted and refused branches; the guard gets only a
   shared reborrow from that access owner.
3. **Occurrence inventory:** independently enumerate each reached caller, helper,
   expression, closure, argument, pattern, return, move and consuming-drop place,
   including fixed initialization, encoder helpers and existing helpers newly
   reached by composition. Bind every entry to exact source bytes, concrete type,
   compiler size/alignment, multiplicity, lifetime and funding phase. A list of
   distinct types or representative captures is insufficient. Count full inline
   `Option<T>` storage when its value is None. Do not infer optimized stack reuse.
4. **Overlap and arithmetic:** reconcile the existing Original foundation and
   phase places by named source occurrence; never subtract an entire old roster
   merely because type names overlap. Independently recompute checked products,
   aligned aggregates, per-phase live sums and proposed total. Reject missing or
   duplicate ownership, arithmetic overflow, arbitrary large floors, omitted
   initializer temporaries or a total that merely adds partial component sums.
5. **Funding order:** fund early ingress/scope/error/return/move storage in the
   single original foundation before Construction or these objects exist.
   Refused export creates no admitted plan/cursor/transfer storage. Capture the
   real previous bound privately from the same ticket; never accept a supplied
   base, alternative equal-byte foundation, new control field or retroactive grant.
6. **Retained lifetime and finalizer:** follow actual outer primary/export/phase/
   cleanup results through caller destruction. Every guard-derived view ends
   before consuming access completion. Actual phase storage is consumed before
   narrowing; actual selected scope and retained results are consumed before
   the unchanged single-floor finish. Unclosed pre-scope failures preserve the
   enlarged charge and original invariant; do not manufacture healthy cleanup.
7. **Writer custody:** verify same-control stop/work checks and exact owner/WASI/
   cache pairing. Reject aliasing against all authentic File identities before
   writing. Preserve every selected writer error and independent cleanup error.
   Review identity rechecks, seek/write/flush/truncate operation boundaries and
   bounded partial-write/Interrupted/zero-write behavior from actual source.
8. **Stop and work closure:** independently count fixed initialization, bounded
   next_block actions and each syscall. Check pre/post stop observations against
   the original cancellation backing/deadline/first-failure rules. The proposed
   indivisible-block amendment needs an explicit root selection; a conservative
   ceiling alone cannot change ExecutionWork units or product budgets.

Independent controls after frozen release:

- Recompute layout sums from fresh exact-source compiler constants, preserving
  raw output and all mismatches. Check zero, boundary, overflow, duplicate and
  missing-occurrence cases with the arithmetic oracle in this packet.
- Positive actual-type compiler control: both access branches feed the same real
  guard/header/rows block; consume concrete phase storage after its lexical end.
- Negative actual-type compiler controls: use the earlier control while access
  lives; move access/scope while a derived view is live; use a view after phase
  completion; extract or construct selected authority externally. Compiler
  rejection must arise from the intended borrow/privacy violation.
- Review nonempty authentic ingress and actual outer error payloads, including
  header refusal and all eight original outcomes. Empty owner fixtures and a
  `.primary` projection cannot qualify the finalizer.

No new genuine writer execution occurs without root's separate exact release.
Native/device/simulator/emulator/UI/capture and process inventories remain paused.
Frozen source-only evidence is not runtime, FieldLog, OTA, store or GA acceptance.
