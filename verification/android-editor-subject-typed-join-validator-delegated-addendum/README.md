# Mandatory raw association join

`delegated_raw.py` exposes the separately frozen API:

```
validate_delegated_raw(raw_row) -> dict
```

It raises `DelegatedRawRefusal` for malformed, missing or contradictory required
raw observations. It never mutates its input, executes a product harness, or
admits execution, authority, helper/body behavior, native, OTA or GA qualification.

The API accepts only the exact source-selected
`setComposingRegionWithAttributes` fixture and its 13 explicitly authored states.
The immutable policy fixes the complete seven-frame caller chain, all method
descriptors, BCIs and source lines, plus source/class hashes and callees verified
against the released semantic roster. It binds the corrected typed-join packet,
module and policy identities as mandatory dependencies. `load_policy` verifies
those three dependency files on every call; relocated consumption must preserve
the verified sibling dependency path. The corrected utility is selected by root
only for typed consistency, not full behavior or source-closure admission.

The raw validator requires `native_sequence`, `frame_sets`, `selected_event`,
captured original/selected receiver+attempt+record authority, actual native
observations and actual public outcome. It joins the exact original native entry
and before-return events, fixed full frame chain and selected state phase. It
validates wrong-receiver/completion observations before any pair filtering. One
original entry/return, exact ordered `(II)Z` then `(II,TextAttribute)Z` normal
observations, typed Boolean values and explicit delegation markers are mandatory
on every normal-return state. Candidate pass/expected fields supply no authority.

Pre-public terminal/dirty/stale/changing states require zero selected native
entries, events and completions and an actual false public outcome. Native-hook
entry states retain the genuine true native result while the public postcheck
returns false. Current/successor preserve true only for this selected edit
fixture; no query-successor policy is generalized. Original hook exceptions bind
the exact exception class and identity to the actual public exception and primary/
first-fatal observation. Those exception rows keep the **native normal scalar
body completion pending**. No scalar result or lambda/helper body return is
inferred from a hook exception or ancestor frame.

All 13 producer raw states and all 13 separate replay raw states pass the narrow
data consistency join. The original nine hostile controls all refuse. Additional
tests cover absent raw backing, strict integral frame/event/entry scalars,
missing normal returns across every normal state, wrong receiver/completion,
wrong state phase/full chain, missing/changed exception and first-fatal identity,
numeric booleans, immutability and dependency pins. These are host data checks;
the existing frozen JVM source/control evidence is reviewed offline.

A compact projection cannot call this API independently. Any compact consumer
must first provide its verified immutable raw backing, validate that raw row and
then reconcile the compact selected event/call-pair/completion projection. The
producer's source/class authenticity and full execution source closure remain
separate mandatory enclosing checks. A self-consistent forged execution is not
authenticated by this data validator. Actual state mutation/authority and full
helper/body admission remain pending in every report.
