# Bounded passive return-observation preparation

Root authorizes an isolated host-test derivative to supply measured nonvoid
results missing from legacy callback events. A beforeReturn event does not by
itself prove the original returned value. The exact sixteen product sources,
all 189 historical dispositions, five separate V1 positives and the complete
selected state obligations remain required.

The proposed derivative is limited to copied ConcreteHostProbe.java, a new
NativeOutcomeProbe.java, and the existing host leaves View.java, ViewGroup.java,
TextView.java, EditText.java, Switch.java and BaseInputConnection.java. The exact
file roster and final patch must be frozen and independently reviewed before
this derivative supplies accepted behavioral evidence. No frozen source or
canonical product edit is authorized by this preparation decision.

Record each actual normal return once after the existing beforeReturn hook,
without reevaluating expressions or changing original branches, hook positions,
counts, callback order or exception identity. Capture original hook-thrown
RuntimeException/Error identity and rethrow the same object. Any failed capture
must cause evidence refusal; it must never manufacture a value or a pass.

A separate qualification hook may run after the existing event, count and
ordinary hook work. Its installation and clearing need an explicit bounded
scenario lifetime. Existing reset semantics stay intact; an unexpected callback
or an unclosed qualification hook refuses the receipt. Preserve earlier runs
that injected before the count update as diagnostics only. Reproduce meaningful
original controls and independent normal/exception/branch equivalence controls
against the exact derivative. Product helper outcomes that the native leaves
cannot observe remain pending unless an actual enclosing typed outcome provides
the required evidence.

The final checker also needs an independently pinned approved context-map hash,
in addition to the immutable semantic-policy hash and exact source/class set.
A context map cannot authorize itself with a reviewed-status string. Changing a
real caller and all matching rows together must fail unless that exact binding
was independently reviewed and selected. Reference-obligation identity is part
of the pinned source closure. Unknown compiler contexts fail closed.

Interface-v2 is a verified draft only. Coherent integration, default full-matrix
qualification, native runtime, public V2, OTA and GA acceptance remain pending.
