This is a separately reviewed Node oracle qualification companion for immutable V7. It does not change the V7 packet or product source and does not select runtime execution.

`companion.py` extends the existing V7 `Prelaunch` facade. Every child retains the base source, actual Rust compiler/sysroot, command-plan, allocator/admission, output and independent cleanup checks. The inherited `selection` SHA string is preserved; the companion uses `node_selection` separately.

Before each child, the companion verifies the exact PATH resolution, canonical Node executable bytes, empty injection environment, unchanged oracle source and fixed 971-byte script with `[node, -e, script]` arguments. Any nonempty `NODE_*`, name containing `DYLD_`, `LD_PRELOAD` or `LD_LIBRARY_PATH` rejects. Installed Node v22.23.3 is pinned by its executable SHA and recorded version-only metadata, not inferred from a filename.

Startup, final verification (including failure exits), and each actual oracle list/execute additionally hash the installed Apple loader, OS version, three physical loaded system libraries, and the complete 82-file dyld cache set (7,048,019,583 bytes). The final measured positive full check took 8.076 seconds. Unrelated Cargo/check/Clippy launches retain basic Node checks without rehashing the entire cache. Oracle relevance requires the actual single fresh Cargo `span_execution_oracle` test artifact in the owned target, its exact bytes, and fixed list/execute arguments. A name alone cannot establish relevance.

`prepare.py` captures Node `--version`, `otool -L`, the OS version, and a version-only loader UUID/path trace. `augment_images.py` independently replays that trace and proves the augmented provenance bytes unchanged. The version trace is not a Wasm execution trace or a per-image cache extraction claim. Full installed cache bytes are bound separately. Existing THIRD_PARTY.yml records development-only Node.js/V8/WASI and Apple platform tools; these are not linked into the Mixer product.

`controls.py` rejects 25 pure mutations, including injection, source/script/executable/cache drift, foreign or stale Cargo artifacts and the former inherited-selection overwrite. The last control invokes the unchanged base event builder with a synthetic process handle and metadata-only reply; it verifies `rootSelectionSHA256` remains the exact root SHA string. No compiler, VM or native runtime was launched. The synthetic Cargo target was removed, all metadata command process groups were independently checked empty, and raw metadata output remains preserved.

The root runtime selection must bind `nodeCompanionSealSHA256` in addition to every unchanged V7 runtime-selection field. The proposed command is `python3 -B companion.py --root-runtime-selection <receipt> --selection-sha256 <receipt-sha> --producer-seal-sha256 79089f1ef382a14e02fbbbf0a6e6dcd0a67158bcfa5354d565a5b037b1d149b2`. No qualified execution is implied by preparing or sealing this companion.
